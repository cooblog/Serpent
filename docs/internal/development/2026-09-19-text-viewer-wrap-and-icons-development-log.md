# 2026-09-19 文本查看器图标按钮与自动换行

> 用户要求文本查看界面：保存和关闭改成图标；文本支持 wrap，名称「自动换行」。
> 工作树内交付，未经用户许可不提交、不推送。

## 处理

顶栏保存/关闭改为图标按钮（Lucide `save` / 既有 `close`），悬停走标准 `data-hover-tip`。新增「自动换行」切换（`wrap-text`），默认开启；同一次会话内切换资产会记住开关。开启时按舞台宽度折行，行号 gutter 隐藏（折行后视觉行与逻辑行对不齐）；关闭时恢复原来的横向撑开与行号。
